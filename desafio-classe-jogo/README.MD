# 🧙 Mini Jogo do Herói

Projeto desenvolvido utilizando:

- Classes e Objetos
- Estruturas de decisão
- Manipulação de DOM
- JavaScript puro (Vanilla JS)

## 🚀 Funcionalidades

- Criação de herói personalizado
- Sistema de ataque baseado no tipo
- Simulação de batalha com chance de vitória/derrota
- Interface simples e interativa

## 📂 Tecnologias

- HTML5
- CSS3
- JavaScript
